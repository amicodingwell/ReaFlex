What ReaFlex does

Pitch correction without hiding the performance.

ReaFlex gives you a note-based editing workflow for vocals while keeping detailed control over tuning strength, timing, vibrato, formants and output.

♪

Visual note editing

Analyze monophonic vocals into editable note blocks and move, resize, split, merge and shape notes directly in the ReaFlex editor.

◎

Centre-pitch correction

Pull sharp and flat notes toward the exact centre of the intended pitch, with adjustable correction strength, confidence and retune speed.

♯

Key & scale snapping

Choose a root and scale, then snap the current note targets into the musical context of the song.

≈

Vibrato preservation

Decide how much natural movement remains after correction instead of flattening every note into a static line.

↕

Per-note control

Switch from overall settings to per-note editing for notes that need different tuning, timing or tonal treatment.

◫

Simple & Advanced modes

Start with the highest-utility controls, then reveal detailed formant, resynth, analysis and navigation settings when you need them.

∿

ReaFlex Resynth

Use the experimental phase-coherent resynthesis backend for custom pitch processing, including adjustable Phase Tightness and natural/robotic tone.

▶

Click-to-audition

Optionally listen to a corrected note directly from the editor when you click it, making small tuning decisions faster.

Installation

Install once. Run it from REAPER.

ReaFlex uses a ReaScript for the editor and a JSFX file for the custom resynthesis backend.

REAPER ReaImGui ReaFlex Lua script ReaFlex JSFX
  1. 01
    Install ReaImGui

    Install ReaImGui through ReaPack if you do not already have it.

  2. 02
    Copy the JSFX

    In REAPER, open the resource path and copy the ReaFlex resynth file into:

    Effects/ReaFlex/
  3. 03
    Load the Lua script

    Open REAPER's Actions list, choose “Load ReaScript”, and select the ReaFlex Lua file.

  4. 04
    Run ReaFlex

    Select a monophonic vocal item, launch ReaFlex, and analyze the take.

Getting started

A simple first-pass workflow.

Start in Simple mode, get the musical result right, and only open Advanced when you need a more surgical adjustment.

01

Select your vocal

Select a dry, monophonic vocal audio item in REAPER, then launch ReaFlex.

02

Analyze the take

Run analysis to detect pitch over time and build editable note blocks.

03

Choose key & scale

Pick the song's musical key and scale. ReaFlex can snap note targets into that context.

04

Set the correction

Use Perfect Tuning, Centre Pitch, Vibrato and Retune controls to define the overall feel.

05

Fix difficult notes

Drag note blocks or switch to Per Note mode for individual corrections.

06

Apply the result

When you're happy, use Apply Take or the available advanced apply tools to commit the processing.

FAQ

Common questions.

What kind of audio is ReaFlex designed for?

ReaFlex is primarily designed around monophonic vocal material where one clear sung pitch is present at a time.

Does ReaFlex replace REAPER's normal editing workflow?

No. ReaFlex is intended to work inside REAPER as a focused vocal-pitch editing layer, while the rest of your session stays in the normal REAPER environment.

What is the ReaFlex Resynth engine?

It is an experimental custom JSFX backend used by ReaFlex for pitch processing. The current phase-coherent version includes controls such as Phase Tightness and natural/robotic formant character.

What is the difference between Simple and Advanced mode?

Simple mode keeps the high-utility tuning controls visible. Advanced mode exposes deeper resynthesis, formant, analysis and navigation settings.

Can I tune individual notes differently?

Yes. Switch to Per Note mode to edit selected notes independently from the overall settings.

Can I hear a note before committing it?

Yes. Enable Listen on Click to audition corrected notes from the editor without applying the take first.
